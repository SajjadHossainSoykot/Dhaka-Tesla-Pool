# Dhaka Tesla Pool

> Share a seat. Split the fare. Survive Dhaka traffic.

Engineering internship MVP for a small ride-pooling system with passengers, a driver/Tesla, pooled rides, per-passenger fares, lifecycle transitions, concurrency-safe seat capacity, Docker, tests, and documented engineering decisions.

The detailed README is completed on the `pre-release` branch after the implementation stabilizes so that the documentation matches the shipped architecture.
